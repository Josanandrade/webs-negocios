# Starters

Bases reutilizables para acelerar futuras demos por tipo de negocio.

Ejemplos futuros:

```text
starters/restaurante/
starters/clinica/
starters/gimnasio/
starters/servicios/
starters/comercio/
```

No guardar aquí datos, textos, imágenes, credenciales ni configuración específica de clientes.

## Disponibles

- `avanttai-booking/`: kit de reserva online white-label que integra el motor de reservas de AvanttAI dentro de la web de un negocio. Incluye proxy de servidor, componente de reserva y tema configurable. Ver su README.
