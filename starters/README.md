# Starters

Bases reutilizables para acelerar futuras demos por tipo de negocio.

Ejemplos futuros:

```text
starters/restaurante/
starters/clinica/
starters/gimnasio/
starters/servicios/
starters/comercio/
```

No guardar aquí datos, textos, imágenes, credenciales ni configuración específica de clientes.
