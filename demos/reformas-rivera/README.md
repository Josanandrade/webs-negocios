# Reformas Rivera · Almensilla (demo comercial)

Demo estática publicada por Cloudflare Pages desde `demo-host/` en la rama `demo/reformas-rivera`.
No indexable: meta robots noindex, `robots.txt` Disallow y `_headers` con `X-Robots-Tag: noindex`.
Sin Railway, sin Wrangler, sin build: HTML + CSS + JS.

- `demo-host/index.html` · página única
- `demo-host/styles.css` · identidad y animaciones
- `demo-host/main.js` · interacción (WhatsApp prellenado, formulario, antes/después, filtros, FAQ)
- `demo-host/assets/og.svg`, `demo-host/favicon.svg`
