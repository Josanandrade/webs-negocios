# Demo · Clínica Podológica María del Carmen Espinosa (Benacazón)

Web de demostración independiente (Next.js, exportación estática). Sin backend: la reserva y la agenda son simuladas en el navegador.

```bash
npm install
npm run dev      # desarrollo
npm run build    # exporta a out/ y comprueba que no se cuela nada interno
npm start        # sirve out/ con cabeceras noindex
```

Notas internas en `docs/INTERNAL_AUDIT.md` (no se publican).
