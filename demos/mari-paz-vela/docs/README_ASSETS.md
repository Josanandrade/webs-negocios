# Recursos visuales · Mari Paz Vela

Todos los recursos son SVG propios, sin fotos de terceros (la red bloquea Instagram, Facebook, Google Maps, Unsplash y OpenStreetMap).

- `demo-host/favicon.svg`: llama sobre fondo noche.
- `demo-host/assets/ilustraciones/`: facial, depilacion, pies, maquillaje (tarjetas de servicios) y centro (sección "El centro").
- `demo-host/assets/galeria/`: cabina, piel, manos, maquillaje, vela. Sustituir por fotos reales del centro cuando las haya (mismo nombre o actualizar `index.html`).
- `demo-host/assets/mapa.svg`: plano ilustrativo, no a escala.

Fuentes de Google Fonts: Gilda Display, Red Hat Text, Red Hat Mono.
