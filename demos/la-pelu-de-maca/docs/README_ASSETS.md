# INTERNO · Fotos y material a pedir — La Pelu de Maca

La demo no usa ninguna foto: no se pudo acceder a material propio verificado
y no se usa stock simulando trabajos. El diseño funciona sin fotos (tarjeta de
cita, etiquetas, notas), pero ganaría mucho con:

1. Retrato de Maca y de Carmen y Mari Carmen (para las etiquetas "Hola, soy").
2. Foto del local / fachada en Av. Reyes Católicos (sección "Pásate").
3. 6–9 trabajos recientes (color, corte, peinado) de @lodemaca.pelu, con permiso.
4. Logotipo, si existe (la web usa un wordmark tipográfico provisional).

Destino: `public/assets/la-pelu-de-maca/` (todo lo que hay en `public/` se sirve).
