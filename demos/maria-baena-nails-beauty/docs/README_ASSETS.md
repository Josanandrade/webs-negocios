# Recursos visuales

No hay fotos públicas reutilizables (Instagram/Facebook bloqueados, web antigua con foto de stock).

`demo-host/assets/galeria/*.svg` son **ilustraciones de referencia** generadas para la demo (francesa, cereza, baby boomer, cromado, línea fina, pedicura). La web las presenta como "diseños de referencia ilustrados", no como trabajos reales.

Para sustituir: guardar fotos reales (JPG/WebP, ~1200 px) con el mismo nombre o cambiar el `src` en `index.html` (sección `#galeria`). `ref. 01` es vertical (3:4), `ref. 06` es panorámica (2:1), el resto cuadradas; `object-fit: cover` recorta el resto. Al usar fotos reales, quitar la frase "Diseños de referencia ilustrados" del encabezado de la galería.
