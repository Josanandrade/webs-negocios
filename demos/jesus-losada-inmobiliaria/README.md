# Jesús Losada · Gestor Inmobiliario — demo comercial

Web estática en `demo-host/` (rama `demo/jesus-losada-inmobiliaria`), publicada por el proyecto compartido de Cloudflare Pages. No se despliega nada de esta carpeta.

- `/` web pública · `/inmueble/?id=<id>` ficha · `/admin-demo/` vista demo del panel.
- Teléfono, WhatsApp, email y zona: `demo-host/assets/js/config.js`.
- Inmuebles ficticios: `demo-host/assets/js/data.js` (marcados como contenido de demostración).
- Ilustraciones propias: `demo-host/assets/inmuebles/*.svg`.
