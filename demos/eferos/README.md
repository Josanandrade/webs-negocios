# Eferos — Demo

Esta carpeta contiene la nueva web demo de Eferos.

## Regla de aislamiento

Todo el código, assets, configuración y documentación específica de Eferos debe vivir dentro de esta carpeta para que pueda extraerse fácilmente a un repositorio independiente si el proyecto pasa a cliente real.

## Ubicación de trabajo

Claude debe crear la aplicación completa dentro de:

```text
demos/eferos/
```

No debe crear archivos de la aplicación de Eferos en la raíz del repositorio.
