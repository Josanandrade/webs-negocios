# Recursos gráficos · Clínica del Pie Alquería

La demo no usa fotografías: no se encontró ninguna imagen pública de la
clínica que pudiera reutilizarse (sin web propia, sin redes localizadas,
galerías de directorios vacías). Todo es tipografía, color y dibujos SVG
propios (marca, mapa esquemático).

Si la clínica facilita fotos (fachada, sala de espera, gabinete, equipo),
irían en esta carpeta. El postbuild elimina este .md de la exportación.
