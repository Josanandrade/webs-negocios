# Clínica del Pie Alquería · demo

Demo comercial (Next.js, exportación estática) para Clínica del Pie
Alquería, podología en Bollullos de la Mitación. Reserva de cita y ficha de
paciente **simuladas**: no se envía ningún dato.

```bash
npm install
npm run dev      # desarrollo
npm run build    # exporta a out/ y comprueba que no haya contenido interno
npm start        # sirve out/ (Railway)
```

Datos del negocio en `src/content/site.ts`. Documentación interna en `docs/`
(no se publica).
