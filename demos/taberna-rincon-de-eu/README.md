# Taberna Rincón de Eu · demo

Demo comercial (Next.js, exportación estática) para la Taberna Rincón de Eu, Pilas (Sevilla). Reserva simulada, sin backend. `noindex`.

```bash
npm install
npm run dev     # desarrollo
npm run build   # exporta a out/ y valida que no se cuela contenido interno
npm start       # sirve out/ con serve (Railway)
```

La investigación y las fuentes están en `docs/INTERNAL_AUDIT.md` (no se publica).
