# Recursos visuales

Todas las imágenes son ilustraciones SVG propias (sin fotos de terceros):

- `demo-host/assets/galeria/`: sillon, maquina, tijeras, peine, degradado, fachada.
- Cabeza de perfil con degradado: `<symbol id="head">` y degradados `fade-*` en `demo-host/index.html`.
- Retrato de Migue: silueta SVG en la sección "Sobre Migue" con la etiqueta "Foto de Migue pendiente".

Sustituir por fotos reales del local y de cortes (Instagram del negocio) cuando se tengan, manteniendo nombres o actualizando el HTML.
